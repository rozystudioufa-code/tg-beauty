# TESTING.md — Руководство тестировщика

## Что это за проект

Telegram Mini App для мастера по наращиванию ресниц. Ванильный JS (без фреймворков),
три файла: `index.html`, `styles.css`, `app.js`. Данные хранятся в `localStorage`.
Бэкенда нет — все записи живут только на устройстве клиента.

---

## Запуск для тестирования

### Вариант A — Браузер (быстро, без Telegram)

```bash
cd tg-app/
python3 -m http.server 8080
```

Открыть: `http://localhost:8080`

> Сузить окно браузера до 390px — имитация мобильного телефона.

**Что работает не так, как в Telegram:**
- `inTelegram = false` (определяется через `!!(tg?.initData)`)
- Кнопка «Записаться» — `showMainButton()` не вызывается, вместо неё отображается inline-кнопка `.btn-book-detail` прямо в контенте
- Отмена записи — вместо `tg.showPopup()` используется двойное нажатие (первое меняет текст на «Точно отменить?», второе подтверждает; сброс через 3 сек)
- `tg.HapticFeedback` — не работает
- `tg.BackButton` — не отображается, вместо неё кнопка «Назад» в шапке экрана

### Вариант B — Телефон по локальной сети

```bash
cd tg-app/
python3 -m http.server 8080
# На телефоне открыть http://[IP-компьютера]:8080
```

## Архитектура навигации

Приложение использует стек (`state.stack`). Три таба — три корневых экрана.

```
[Главная]  [Услуги]  [Записи]   ← нижняя навигация (activateTab)
                ↓
          Детали услуги          ← navigateTo('detail')
                ↓
          Дата и время           ← navigateTo('datetime')
                ↓
          Подтверждение          ← navigateTo('confirm')
                ↓
          Успех                  ← navigateTo('success') + 900мс задержка
```

Переключение таба сбрасывает стек и скрывает все промежуточные экраны.

### TC-07 — Выбор даты и времени

**Слоты (из `data.js`):**
- Будни (пн–пт): `09:00`, `12:00`
- Выходные (сб–вс): `12:00`

**Сценарии:**

| Сценарий | Ожидаемый результат |
|----------|---------------------|
| Слот свободен | Кнопка активна, клик выделяет слот |
| Слот занят (другая запись перекрывает) | Кнопка не отображается |
| Выбрать слот | Появляется кнопка «Записаться на HH:MM →» под сеткой слотов |
| Прокрутить полосу дат | Видны ближайшие 14 дней; прошедшие дни недоступны |

**Логика конфликта слотов (`getAvailableSlots`):**
Запись на 09:00 с длительностью 120 мин блокирует диапазон 09:00–10:59. Слот 12:00 остаётся доступным (условие: `slotMin >= bStart && slotMin < bEnd`).

## LocalStorage — ключи и структура

| Ключ | Тип | Значение |
|------|-----|----------|
| `tg_beauty_bookings` | JSON array | Список всех записей |
| `tg_beauty_offer_shown` | string `'1'` | Оффер был показан |
| `tg_beauty_onboarded` | string `'1'` | Онбординг был показан |

## Известные ограничения

| Ограничение | Описание |
|-------------|----------|
| Записи только локальные | `localStorage` — данные не синхронизируются между устройствами и не видны мастеру |
| Уведомления не работают | Текст «Напоминание придёт…» — декларативный, бот не имеет бэкенда |
| Депозит не реализован | Поле `deposit: 0` у всех услуг, оплата не подключена |
| Слоты статичные | `WEEKDAY_SLOTS = ['09:00', '12:00']`, `WEEKEND_SLOTS = ['12:00']` — управляются только через `data.js` |
| `MainButton` только в Telegram | В браузере рендерится inline-кнопка `.btn-book-detail` |
