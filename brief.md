# Brief: Telegram Mini App — каталог мастера по наращиванию ресниц

> Версия: MVP (v1.0)  
> Язык интерфейса: русский  
> Дизайн: Telegram-нативный (themeParams, MainButton, BackButton)  
> Целевая платформа: мобильный Telegram (iOS + Android)

---

## Принципы интерфейса

- Минимум текста, максимум фото
- Кнопки минимум 44px, касания комфортные одним большим пальцем
- Все цвета берутся из `themeParams` — светлая и тёмная тема без доработок
- Никакой регистрации — имя и ID из Telegram
- Максимум 6 тапов от открытия до подтверждения записи
- Приложение, а не сайт: нет горизонтального скролла страницы, нет мелкого текста, нет desktop-элементов

---

## Навигация

```
[ Главная ]  [ Услуги ]  [ Мои записи ]
  (tab 1)     (tab 2)      (tab 3)
```

- Нижняя панель (Bottom Tab Bar) — 3 вкладки
- Флоу записи открывается поверх как стек экранов (BackButton закрывает шаги)
- Кнопка «Назад» — только Telegram BackButton API, без кастомных стрелок

### Экран 1 — Главная

**Путь:** Открытие приложения → вкладка «Главная»

**Что видит пользователь:**

```
┌─────────────────────────────┐
│  [фото]  Имя мастера        │
│          Наращивание ресниц │
│          ● Принимаю клиентов│
├─────────────────────────────┤
│  Ближайшее время:           │
│  Пятница, 23 мая · 11:00    │
│  [  Записаться →  ]         │
├─────────────────────────────┤
│  Последние работы           │
│  [фото] [фото] [фото] [фото]│  ← горизонтальный скролл
├─────────────────────────────┤
│  ❝ Отличный результат,      │
│    держится уже 4 недели ❞  │
│    — Анна К.                │
└─────────────────────────────┘
[ Главная ]  [ Услуги ]  [ Записи ]
```

**Элементы:**
- Круглый аватар мастера (56px) + имя + специализация
- Зелёная точка + статус «Принимаю клиентов» / «Запись закрыта»
- Блок «Ближайшее время» — конкретная дата и час ближайшего свободного слота
- Кнопка «Записаться →» (primary, высота 52px, полная ширина)
- Горизонтальный скролл фото работ — 4 карточки, квадратные (1:1), с тенью
- Один отзыв — короткая цитата + имя клиентки (без отдельного экрана)

**Действия:**
- Тап «Записаться →» → Экран 2 (Каталог услуг)
- Тап на фото работы → открывается в нативном просмотрщике Telegram
- Тап на вкладки навигации

**Переходы:**
- «Записаться» → Экран 2
- Фото → нативный просмотр (не отдельный экран приложения)

**Элементы:**

### Экран 4 — Выбор даты и времени

**Путь:** Детали услуги → «Выбрать дату»

**Что видит пользователь:**

```
← (BackButton)
┌─────────────────────────────┐
│  Объём 2D–3D · 3 200 ₽     │  ← sticky сводка вверху
├─────────────────────────────┤
│  [Пн 19][Вт 20][Ср 21]     │  ← горизонт. скролл дат
│  [Чт 22][Пт 23][Сб 24]...  │
├─────────────────────────────┤
│  Пятница, 23 мая            │
│                             │
│  [ 10:00 ] [×11:00] [12:00] │
│  [ 13:00 ] [ 15:00] [×17:00]│
│                             │
│  × — занято                 │
└─────────────────────────────┘
[   Выбрать этот слот →      ]  ← MainButton (неактивна до выбора)
```

**Элементы:**
- Sticky-строка вверху: название услуги + цена (не скроллируется)
- Горизонтальная полоса дат — 14 дней вперёд, прокрутка
  - Активная дата — акцентный цвет
  - Даты без слотов — серые, некликабельны
- Сетка слотов (3 колонки):
  - Доступен — обведённая кнопка
  - Занят (×) — серый, некликабелен
  - Выбран — залитый акцентным цветом
- `MainButton` неактивна, пока слот не выбран; активируется после выбора

**Действия:**
- BackButton → Экран 3
- Тап на дату → обновление сетки слотов (без перехода на новый экран)
- Тап на слот → выбор (haptic feedback), активация MainButton
- MainButton «Выбрать этот слот →» → Экран 5

**Переходы:**
- MainButton → Экран 5 (с параметрами: услуга + дата + время)

```
│                             │
│  Отмена за 24ч — бесплатно  │
│  Позже — депозит не возврат.│
├─────────────────────────────┤
│  Комментарий (необязательно)│
│  [________________________] │
└─────────────────────────────┘
[    Оплатить депозит 700 ₽  ]  ← MainButton
```

**Элементы:**
- Заголовок «Проверьте запись»
- Карточка сводки: услуга / дата / время / длительность / цена
- Блок депозита: сумма + пояснение «я держу это время только для вас»

**Действия:**

**Переходы:**
- После успешной оплаты → Экран 6
- После ошибки оплаты → остаться на Экране 5 + `showPopup()` с текстом ошибки

**Итого: 6 тапов** от открытия до подтверждённой записи.

## Чего НЕ будет в v1

| Что | Почему отложено |
|---|---|
| Экран «О мастере» / профиль | Достаточно имени и статуса на главной |
| Полноценная галерея работ | Фото «до/после» прямо в карточке услуги решает задачу |
| Программа лояльности / баллы | Сложная бэкенд-логика, не критично для запуска |
| Отзывы — отдельный экран | Один отзыв на главной + один на детали услуги = достаточно |
| Настройки уведомлений | Напоминания работают автоматически, настройка — v2 |
| Лист ожидания | Полезно, но не блокирует запуск |
| Реферальная программа | Запустить после первых 20–30 записей |
| Несколько мастеров | Приложение для соло-мастера |
| Корзина / несколько услуг за раз | Усложняет флоу, нетипично для ресниц |
| Поиск по услугам | Услуг мало, хватит фильтрации по табам |
| Онбординг / туториал | Интерфейс достаточно простой |
| Смена языка | Только русский |
| Веб-версия | Только Telegram |

## Технические требования к реализации (из brief)

| Требование | Решение |
|---|---|
| Нативный вид Telegram | `themeParams` для всех цветов, TelegramUI компоненты |
| Кнопки ≥ 44px | Все интерактивные элементы min-height: 44px, touch target |
| Адаптация клавиатуры | `WebApp.viewportStableHeight` для расчёта высоты экрана |
| Нет белого экрана при загрузке | Скелетон-экраны + `WebApp.ready()` в первой строке |
| Двойные тапы | `MainButton.showProgress()` + idempotency keys на API |
| Безопасность | Серверная валидация HMAC `initData` на каждом запросе |
| Сохранение состояния | CloudStorage — только на переходах между шагами |
| Оплата | `openInvoice()` + reconcile статуса через bot webhook |
| Слоты | Пессимистичная блокировка с TTL 10 минут |
| Подтверждение | Bot API sendMessage после успешной оплаты |
| Напоминания | Bot API sendMessage за 24ч и за 2ч до записи |
